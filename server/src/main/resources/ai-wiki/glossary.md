# 术语表（回答用户时用大白话转述，不要把术语丢给用户）

## 订单与格口

- **寄存单（orderNo）**：用户的一次寄存，状态从进行中到已结束/已取消。
- **格口（slotNo）**：柜子里的一个格子，编号如 A-03。
- **柜机（cabinetNo）**：一整台柜子，位于某个点位。
- **点位（site）**：柜机所在的场所（某超市/某楼栋），报修时要说清点位与柜机编号。

## 格口异常（系统自动检测的结果）

- `DOOR_OPEN`：门开着没关。
- `CONTENT_LEFT`：订单结束后柜内检测到有物品（遗留物）。
- `CONTENT_UNVERIFIED`：关了门但拿不到"柜内已空"的凭据（红外/重量/AI 都没给结论）。
- `SENSOR_CONFLICT`：传感器结论互相矛盾。

## 工单系统

- **工单**：一件事的登记与流转，带类型、紧急程度、处理时限。
- **线上队列（ONLINE）**：线上业务员处理，靠电话/站内消息联系用户。
- **线下队列（FIELD）**：现场运维到场处理。线下单由业务员从线上单派生，客服不直接建线下单。
- **父单/子单**：线上单是父单，派生的线下单是它的子单。

## 常见事件流水

- `CREATED` 开单、`REPEATED` 同一现象再次被观察到（合并到已有单）、
- `CLAIMED` 被认领、`RESOLVED` 人工处理完结、`AUTO_CLOSED` 现场自愈（如门被代关）留底、
- `PHONE_CALLED` 业务员已电话联系、`RETRIEVED_BY_OWNER` 物主自助取回遗留物。

## 计费口径

- 价格单位是"点"，1 点 = 1 分钱。账户里充的是点数。
